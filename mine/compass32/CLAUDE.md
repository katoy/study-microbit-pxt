# Compass32 プロジェクト固有設定

## プロジェクト概要

32方向高精度方位磁石。約 11.25° 刻みで 360° を32方向に分割。先端と後端を結ぶ直線を輝度グラデーション（`led.plotBrightness`）で描画します。

## 固有情報

### 仕様
- **方向数**: 32方向（約 11.25° 刻み）
- **表示方式**: 先端（外周）→ 後端（対向する反対側）を結ぶ直線矢印
- **輝度表示**: グラデーション（先端: 100% 輝度、後端: 約 10% 輝度）
- **メモリ最適化**: 座標 `(x, y)` を `10x + y` でパック（例: `(2,0) → 20`, `(2,4) → 24`）

### ロジック構成
- `src/compass32.ts` - 32方向判定ロジック & 描画データテーブル
- `src/app.ts` - イベントループ（SSOT 結合対象）

### 描画データテーブル
```typescript
// DIRECTION_POINTS[インデックス] = [[先端座標], [胴体座標], ..., [後端座標]]
// 各座標は (x, y) を 10x + y でパック
```

**主要方位の例**:
- インデックス 0: 0° (真北) - 先端 (2,0), 後端 (2,4)
- インデックス 4: 45° (北東) - 先端 (4,0), 後端 (0,4)
- インデックス 8: 90° (東) - 先端 (4,2), 後端 (0,2)
- インデックス 16: 180° (南) - 先端 (2,4), 後端 (2,0)

## 開発時の注意

- **編集対象**: `src/compass32.ts` の描画データテーブル
- **禁止**: `main.ts` は自動生成ファイル。直接編集しない。
- **座標パック**: `10x + y` 形式で定義。展開時は `x = Math.floor(val / 10)`, `y = val % 10`
- **輝度表示**: `led.plotBrightness(x, y, brightness)` で グラデーション表現
