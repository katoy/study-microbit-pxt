# Compass-Degit プロジェクト固有設定

## プロジェクト概要

方位磁石そろばん表示版。北方向からのずれの角度を LED マトリクスにそろばん形式で表示します。東回り（時計回り）は `+` 、西回り（反時計回り）は `-` で符号付き表示。

## 固有情報

### 仕様
- **表示形式**: そろばん形式の符号付き数値（`+000` 〜 `+180` または `-001` 〜 `-179`）
- **符号表示**: 左2列（X=0, 1）で `+` または `-` を表示
- **数値表示**: 右3列（X=2, 3, 4）で百・十・一の位をそろばん珠で表示

### ロジック構成
- `src/compass.ts` - そろばん変換 & 符号計算ロジック
- `src/app.ts` - 計測・表示ループ（SSOT 結合対象）

### LED マトリクス表示
```text
   X=0  X=1  X=2  X=3  X=4
Y=0 [符号 ] [百] [十] [一]  <-- 五玉 (0 or 5)
Y=1 [符号 ] [百] [十] [一]  <-- 一玉
Y=2 [符号 ] [百] [十] [一]  <-- 一玉
Y=3 [符号 ] [百] [十] [一]  <-- 一玉
Y=4 [符号 ] [百] [十] [一]  <-- 一玉
```

### テスト対象
- 角度計算とそろばん変換の網羅テスト（単位テスト：Vitest）
- 符号判定（東回り/西回り）の検証

### 自動同期
SSOT 対応。

```bash
npm run build       # ビルド + 自動同期
npm run test:unit   # ユニットテスト + 自動同期
```

## 開発時の注意

- **編集対象**: `src/compass.ts` のそろばん変換ロジック
- **禁止**: `main.ts` は自動生成ファイル。直接編集しない。
- **表示検証**: LED マトリクスの点灯パターンを手動確認する際は、`+` / `-` の符号表示が正しいか確認
